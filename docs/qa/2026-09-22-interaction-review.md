# 2026-09-22 交互回归审查

范围：基于 `1b2ec6f`，检查添加供应商、快速切换、请求日志、MCP / Skills 编辑、路由演示和官网下载入口。本轮优先修复真实操作缺陷，不扩展后台业务能力。

## 已复现与修复

| 问题 | 根因与处理 | 验证 |
| --- | --- | --- |
| 日志搜索供应商名称导致整页白屏 | `useMemo` 使用尚未初始化的 `nameOf`；将其初始化移到筛选之前 | 修复前搜索 `CoderPlan` 白屏；修复后返回两条记录，控制台无错误 |
| 日志筛选无结果误报“暂无请求” | 区分空库与筛选无结果，提供重置入口 | 无匹配 → 重置 → 仅失败 → 刷新保留筛选通过 |
| 日志异步加载可更新过期页面 | 请求序号和 effect 清理忽略过期结果；按 CLI 重建日志页状态；失败显示重试提示 | 构建检查通过；原生 IPC 慢响应和失败仍需桌面验证 |
| 日志详情缺少模态键盘行为 | 使用现有 Radix Dialog，时间单元格提供键盘可聚焦按钮 | 打开详情后 Escape 关闭，不离开日志页 |
| 快速切换搜索残留旧条目 | 跨 CLI 演示数据共享 ID；列表 key 改为 CLI + ID | URL 搜索恰好返回五个匹配项，无残留条目 |
| 数字开头搜索误切换供应商 | 输入框聚焦时不拦截数字；空结果时保持合法选中索引 | 首字符 `1` 留在输入框；空结果 → Escape → 搜索 → Enter 通过 |
| 预设按钮嵌套 Key 链接 | 使用非交互容器、独立选择按钮及链接；浏览器保留链接默认行为 | 无障碍树中按钮、链接为同级；未访问外部密钥页面 |
| Skill 校验失败仍关闭编辑器 | 成功保存后才关闭；保存期间禁用重复提交及关闭 | 修复前非法 frontmatter 丢失编辑界面；修复后草稿保留，修正内容可保存 |
| 新建远程 MCP 无法进入 URL 表单 | 根据协议类型判断远程模式，而非 URL 是否非空 | 选择 HTTP、填写 URL、演示保存通过 |
| MCP 保存失败提前关闭 | 成功后关闭，失败保留草稿，保存期间禁用操作 | 构建通过；原生 IPC 失败场景待桌面验证 |
| 设置路由在演示模式无可用数据 | 增加本地演示规则、排序、开关、Fallback 和试运行；明确标注不真实转发且切换 CLI 重置示例 | `o3-mini` 命中规则并显示备用供应商 |
| 官网下载过度依赖 UA 推断芯片 | Mac 显式选择 Apple / Intel；移动、未知及 ARM Linux 进入全部下载 | 六种模拟 UA 的主按钮、导航链接目标断言通过 |
