# 2026-10-07 导航与路由预览回归

本轮保持“核心入口 + 更多”的已有功能分层,不新增业务功能,不改真实 CLI 配置和后端路由规则。

## 第一轮:导航交互

- 原自绘菜单没有外部点击/键盘焦点处理,进入高级页面后还会自动重新展开。改用 Radix Dropdown Menu,选择后收起,Esc 仅关闭菜单并归还焦点,保留当前页面及选中标识。
- 底部布局仍向下弹出菜单,在 1000×680 窗口中菜单起点为 y=676.5,大部分内容不可见。现在按导航位置选取弹出方向,并自动避让窗口边界。
- 横栏点击当前 CLI 时被提前返回,因此从高级页面无法回到该分组。高级页面不再错误标记 CLI 为当前页面,重新点击可返回。
- 窄屏横栏的 CLI 列表原先挤占添加和快速切换按钮;现在分行显示操作区,CLI 列表独立横向滚动。
- 独立代码复审发现 Radix 默认阻止 Tab 离开菜单。补充 Tab/Shift+Tab 关闭菜单并按触发按钮的正常顺序继续移动焦点,四种布局均先复现再修复。

## 第二轮:路由预览准确性

- 编辑或清空输入会立即使旧请求失效,慢响应与失败结果均不能覆盖新状态。
- 供应商列表或网关配置修订变化时清除旧预览;组件卸载同样使未完成请求失效。
- 请求执行中阻止重复 Enter/建议模型提交,输入法组词确认不会触发试算。
- Demo 的默认路径跟随当前选中的供应商,不再固定选择列表首项。
- 窄屏试算按钮补充可访问名称,错误和结果提供可读屏状态提示。

## 第三轮:展示与文档一致性

- 官网深浅色截图重新从当前中文 Demo 捕获,移除旧截图中已下沉的一级导航。
- 中英文指南明确高级功能位于“更多”,并修正接管管理入口路径。
- 设计文档说明最近一次实际去向位于网关详情,不再错误描述为首页常驻。

1. 选择高级页面后菜单收起。
2. Esc 关闭菜单、保留日志页并归还焦点。
3. 点击空白关闭菜单。
4. ArrowDown 打开菜单、End 导航到末项。
5. 底部菜单完整位于窗口内。
6. 顶部横栏点击当前 CLI 可从高级页返回。
7. Demo 切换默认供应商后试算使用新默认值。
8. 已显示的预览随供应商变化失效。
9. 编辑输入后忽略在途旧响应。
10. 清空输入后忽略在途旧响应。
11. 重复 Enter 不产生并发重复试算。
12. IME 的 Enter 不提交试算。
13. 旧请求失败不替换较新的成功结果。
14. 当前试算失败可被读屏识别并可重试。
15. 菜单打开指南后焦点进入对话框。
16. 从网关管理返回时旧预览失效。
17. 顶部窄屏固定操作可点击,末端 CLI 可滚动到并选择。
18. 底部窄屏固定操作可点击,末端 CLI 可滚动到并选择。
19–26. 四边导航分别使用 Tab 和 Shift+Tab 退出菜单,焦点落在触发按钮相邻的正常控件。

## 测试时序排查

- 生产构建曾在切换供应商后立即读取 DOM 时误报旧预览仍存在。20 次观测均在点击后约 3.5–7.5ms 清除结果,属于 React 状态提交时序。测试改为等待结果节点移除,没有为测试修改应用逻辑。
- 早期执行还出现过 2.5 秒点击稳定性等待超时;最终开发/生产完整重跑均通过,没有以强制点击或禁用动画跳过交互检查。
