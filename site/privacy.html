隐私说明

最后更新:2026-11-06 · keyway.one

要点

本网站不使用 Cookie、不嵌入统计脚本、不做用户追踪。没有 Google Analytics,没有像素,没有行为采集。

我们(不)收集什么

  • 不收集个人信息、设备指纹或访问行为数据;网站静态资源由我们自己的服务器直接提供,服务器日志仅用于故障排查与汇总访问统计,不用于画像或与第三方共享。
  • 安装包托管在 GitHub Releases,下载与更新请求受 GitHub 自身的隐私政策约束。
  • 如你通过 GitHub Issues 反馈,相应内容按 GitHub 平台规则处理。

Keyway 应用本身

Keyway 是本地优先的桌面应用:供应商配置与 API Key 存储在你本机的加密数据库中,不上传任何服务器。代理转发时,请求内容与认证信息会发送给你选择的上游供应商,受该供应商的隐私政策约束。详见项目博客。
