把你的服务接进 Keyway

2026-11 发布 · 适用于 AI API 供应商、聚合网关与模型服务

Keyway 是开源(MIT)的 AI CLI 本地网关,macOS / Windows / Linux 桌面端。用户在 Claude Code、Codex、Gemini CLI、OpenCode 等 9 个 CLI 里管理供应商、切换、配置故障转移。对你的服务来说,接入 Keyway 意味着出现在这些用户的「添加供应商」列表里——配好名称和地址,一次点击就完成。

接入由浅入深有三层,做到第几层由你决定:

三层接入,由浅入深

层级用户侧体验你要做的事
兼容端点用「自定义供应商」手动填地址接入提供 OpenAI 或 Anthropic 兼容端点——仅此而已
预设收录在列表里直接点你的名字,地址自动填好,还能一键跳你的控制台取 Key提交收录申请,通过审核后随版本更新内置
一键接入按钮在你的控制台点「添加到 Keyway」,Keyway 弹出预填好的确认框,只填 API Key在页面放一个 keyway:// 深链按钮

申请预设收录

收录是公开的代码贡献,不是远程配置下发:预设列表写在 Keyway 的开源仓库里,Keyway 不会从你的服务器读取预设、不远程执行代码、不接收用户的 API Key。流程四步:

  1. 通过 收录申请表单 提交官网、公开 API 文档、Base URL、协议与模型等公开信息;
  2. 维护者核对官方文档、端点安全性、协议兼容性与实际连通性;
  3. 通过审核的内容整理为 预设 PR(你也可以直接提);
  4. PR 合并后,下一次版本发布把预设带给所有用户,已装用户自动更新获得。

审核标准

  • 官方端点:模型厂商自己的 API,免费收录;
  • 第三方与聚合服务:运营满 3 个月、有公开文档与定价、无重大安全或停运事故,免费收录;
  • 赞助位:付费收录,条目带明示的「赞助」角标,不做隐性推广;取 Key 链接必须是干净的控制台地址,不允许 ?aff= 之类的推广参数;质量底线不因赞助放宽,端点不可用即下架。
红线:提交内容不得包含 API Key、账号密码、用户数据或推广参数。预设里的取 Key 入口必须是你官方控制台的干净地址。

「添加到 Keyway」按钮(深链)

Keyway 注册了 keyway:// 协议。用户已安装 Keyway 时,点击你页面上的按钮,Keyway 会弹出确认框——端点、名称都已预填,用户只需粘贴 API Key。没有装 Keyway 的用户,建议把链接的兜底跳转指向 下载页。手把手教程(含未安装兜底 JS、放置位置与测试方法)见《在你的平台接入 Keyway:一个按钮的事》。

链接格式:

keyway://connect/relay?v=1&base=https%3A%2F%2Fapi.example.com&app=claude&name=Example
参数必填说明
v是固定为 1
base是你的接口根地址,URL 编码;必须是 HTTPS,不带用户名密码、查询参数或锚点。OpenAI 兼容端点填根地址即可,Codex 场景 Keyway 会自动补 /v1
app是目标 CLI:claude / codex / opencode / openclaw,多 CLI 就放多个按钮
name否预填的显示名,40 字符以内
model否预选的模型 ID
handoff否短时一次性授权码,用于免复制粘贴的 Key 交接,高级集成,建议先通过 Issue 对齐

放到你的控制台或文档页:

<a href="keyway://connect/relay?v=1&amp;base=https%3A%2F%2Fapi.example.com&amp;app=claude&amp;name=Example">
  添加到 Keyway
</a>
安全红线:深链只承载公开连接信息。任何情况下不要把 API Key、账号或其他机密拼进链接——Key 由用户在 Keyway 内粘贴,或走短时一次性的 handoff 授权。

常见问题

收录要收费吗?

不收费。官方端点、以及运营满 3 个月且有公开文档定价的优质第三方服务都免费收录。赞助位是额外的明示推广位,不买不影响收录。

收录后多久生效?

审核通过后随下一次版本发布生效;已安装用户通过自动更新获得,无需重新下载。

深链按钮和预设收录冲突吗?

不冲突,建议都做:预设解决「被发现与被信任」,深链解决「从你的控制台一步完成配置」。

用户添加后,Keyway 会对我的端点做什么?

用户主动点「测试连通」时,Keyway 会发一条最小请求验证可用性与延迟;平时只是把用户请求按配置转发。Keyway 不读取你的服务器配置,也不向你的服务器上报数据。

让 Keyway 用户一步用上你的服务

提交公开信息,审核通过即随版本内置;深链按钮随时可以先行上线。
