在你的平台接入 Keyway:一个按钮的事

2026-11 发布 · 适用于 API 供应商、聚合网关与工具平台的站长和前端开发者

你的用户里,有一批人在 Claude Code、Codex 这类 AI CLI 里写代码。他们要把你的服务配进 CLI,通常要复制端点、打开配置文件、粘贴 Key——每一步都在流失。Keyway 是开源(MIT)的 AI CLI 本地网关,你可以在自己的控制台或文档页放一个「添加到 Keyway」按钮:用户点一下,Keyway 弹出已预填你家端点的确认框,用户只粘贴 API Key,完成。全程不离开你的平台。

TeapotRouter 官网已上线同样的入口,本文就是教你做这件事——全部工作量约半小时。

用户会经历什么

用户状态点击后
已安装 KeywayKeyway 窗口弹出确认框:端点、名称已预填,用户粘贴 API Key 即完成添加;之后可一键接管 CLI、随时切换供应商
未安装深链无反应——所以第 3 步的兜底跳转是必做的(把用户送去 Keyway 下载页,装完回来再点一次即可)
安全边界:深链里只放公开连接信息(端点、品牌名),永远不要把用户的 API Key 拼进链接——Key 由用户在 Keyway 里自己粘贴。

第 1 步:拼出深链

Keyway 安装时注册了 keyway:// 协议。链接格式:

keyway://connect/relay?v=1&base=https%3A%2F%2Fapi.你的域名.com&app=claude&name=你的品牌名
参数必填说明
v是固定 1
base是你的接口根地址,URL 编码;HTTPS,不带用户名密码、查询参数、锚点。OpenAI 兼容端点填根地址,Codex 场景 Keyway 自动补 /v1
app是claude / codex / opencode / openclaw,服务多个 CLI 就放多个按钮
name否预填显示名,40 字符以内

参数的完整约束与安全模型见供应商接入指南。

第 2 步:放按钮

最简单的形态,一个普通链接就够:

<a href="keyway://connect/relay?v=1&amp;base=https%3A%2F%2Fapi.你的域名.com&amp;app=claude&amp;name=你的品牌名">
  添加到 Keyway
</a>

放在哪转化最高(按实测优先级):

  • 控制台 API Key 页——用户刚生成 Key 的那一刻,意愿最强;
  • 接入文档的「客户端使用」节——和 Claude Code 手动配置教程并排,给用户「省事版」选项;
  • 首页/定价页的次要位置——可作补充。

品牌素材与推荐文案模板见接入指南的「推荐给你的用户」一节。

第 3 步:未安装兜底(必做)

未安装 Keyway 的用户点击深链没有反应,直接放裸链接会把这批人丢掉。用这段 JS 兜底:点击时尝试唤起,约 1.5 秒后页面仍可见(说明应用没起来)就送去下载页。

<script>
  document.querySelectorAll('a[href^="keyway://"]').forEach(function (btn) {
    btn.addEventListener('click', function (e) {
      e.preventDefault();
      var deepLink = btn.href;
      var start = Date.now();
      // 1.5s 后若页面仍可见且未离开,判定未安装 Keyway
      setTimeout(function () {
        if (!document.hidden && Date.now() - start < 1600) {
          window.location.href = 'https://keyway.one/download.html';
        }
      }, 1500);
      window.location.href = deepLink;
    });
  });
</script>

装好 Keyway 的用户会被系统唤起应用、页面切到后台,document.hidden 为真,不会触发跳转;只有真正没装的用户才会落到下载页。下载页有 macOS / Windows / Linux 全平台安装方式。

第 4 步:测试

  1. 快速验证深链:浏览器地址栏直接粘贴 keyway://… 链接回车,装了 Keyway 的机器应弹出确认框;
  2. 走全流程:确认框里粘贴一个测试 Key,检查 Keyway 里的端点、名称是否与你预期一致(Codex 场景注意 /v1 是否按预期补上);
  3. 兜底分支:找一台(或临时改名 keyway 协议所在的)未装 Keyway 的设备点按钮,确认 1.5 秒后落到下载页;
  4. 链接体检:base 必须无查询参数和锚点,name 不超过 40 字符,否则 Keyway 会拒绝这次连接。

常见问题

接入有门槛或收费吗?

没有。深链是 Keyway 的开放能力,不申请、不审核、不收费,按本文接入即可用。若还想进入 Keyway 的预设列表(用户添加供应商时直接点你的名字),走收录申请,两者互补。

链接里能带上用户的 Key,做到全自动吗?

不能,也不应该。深链只承载公开连接信息;Key 涉及机密,由用户在 Keyway 端粘贴(高级场景有短时一次性的 handoff 授权,见接入指南)。

我能知道有多少用户从这个按钮进来吗?

按钮在你自己的页面上,点击量你的埋点/日志天然可见;Keyway 侧不回传数据给你——它是本地优先工具,不向你的服务器上报。

支持哪些 CLI?

深链支持 Claude Code、Codex、OpenCode、OpenClaw 四个;Gemini CLI 等其余分组通过预设收录覆盖。
