Privacy

Last updated: 2026-11-06 · keyway.one

The short version

This website sets no cookies, embeds no analytics, and performs no user tracking. No Google Analytics, no pixels, no behavioral profiling.

What we (don't) collect

  • We do not collect personal data, device fingerprints, or browsing behavior. Static assets are served directly from our own server; server logs exist for troubleshooting and aggregate traffic statistics only, never for profiling or third-party sharing.
  • Installers are hosted on GitHub Releases; downloads and update checks are subject to GitHub's own privacy policy.
  • If you reach out via GitHub Issues, that content is handled under GitHub's platform rules.

The Keyway app itself

Keyway is a local-first desktop app: provider configuration and API keys live in an encrypted database on your machine and are never uploaded. When proxying requests, content and credentials are sent to the upstream provider you choose, under that provider's privacy policy. See the project documentation.

Contact

For privacy questions, contact the maintainer (anmutu) via GitHub Issues.
