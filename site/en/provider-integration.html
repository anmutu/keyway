Get your service into Keyway

Published 2026-11 · For AI API providers, aggregators and model services

Keyway is an open-source (MIT) local gateway for AI coding CLIs on macOS, Windows and Linux. Users manage providers, switch between them, and set up failover across Claude Code, Codex, Gemini CLI, OpenCode and nine CLIs in total. For your service, being in Keyway means appearing in the "Add provider" list — name and endpoint pre-filled, one click to configure.

There are three levels of integration, from shallow to deep:

Apply for a preset listing

A listing is a public code contribution, not remote configuration: presets live in Keyway's open repository. Keyway never reads presets from your servers, never executes remote code, and never receives users' API keys. Four steps:

  1. Submit public info — website, public API docs, base URL, protocol and models — via the listing request form;
  2. A maintainer verifies the docs, endpoint safety, protocol compatibility and live connectivity;
  3. Approved entries become a preset PR (you may open it yourself);
  4. Once merged, the next release ships the preset to every user; installed users get it via auto-update.

Review criteria

  • Official endpoints: model vendors' own APIs — listed free;
  • Third-party and aggregator services: operating for 3+ months, public docs and pricing, no major security or abandonment incidents — listed free;
  • Sponsored slot: paid, with a clearly labelled badge — no stealth promotion. The key-console link must be a clean official URL without ?aff=-style tracking; quality bars do not relax for sponsors, and an unusable endpoint gets delisted.
Hard lines: submissions must not contain API keys, credentials, user data or promo parameters. The key URL in a preset must be your official console address, clean.

The "Add to Keyway" button (deep link)

Keyway registers the keyway:// scheme. When a user with Keyway installed clicks the button on your page, Keyway opens a confirmation dialog — endpoint and display name pre-filled; the user only pastes an API key. For users without Keyway, point the fallback link at the download page. For a hands-on walkthrough (fallback JS, placement advice and testing), see "Integrate Keyway into your platform: it's one button".

Link format:

keyway://connect/relay?v=1&base=https%3A%2F%2Fapi.example.com&app=claude&name=Example
ParamRequiredDescription
vyesFixed: 1
baseyesYour API root, URL-encoded; must be HTTPS with no userinfo, query string or fragment. For OpenAI-compatible endpoints supply the root — Keyway appends /v1 for Codex
appyesTarget CLI: claude / codex / opencode / openclaw — one button per CLI if you serve several
namenoPre-filled display name, up to 40 characters
modelnoPre-selected model ID
handoffnoShort-lived, single-use grant for copy-free key exchange. Advanced — align with us over an issue first

Drop it into your console or docs page:

<a href="keyway://connect/relay?v=1&amp;base=https%3A%2F%2Fapi.example.com&amp;app=claude&amp;name=Example">
  Add to Keyway
</a>
Security line: deep links carry public connection info only. Never put API keys, accounts or secrets into the link — keys are pasted by the user inside Keyway, or exchanged via a short-lived, single-use handoff grant.

FAQ

Does listing cost anything?

No. Official endpoints and established third-party services (3+ months, public docs and pricing) are listed free. The sponsored slot is a separate, clearly labelled option — skipping it changes nothing about usability.

How long until it goes live?

After review, the preset ships with the next release; installed users receive it via auto-update.

Deep-link button vs. preset listing?

Not either/or — do both. The preset covers discovery and trust inside Keyway; the button covers one-click setup from your console.

What does Keyway do with my endpoint after a user adds it?

When the user clicks "Test", Keyway sends one minimal request to check availability and latency; otherwise it simply forwards the user's requests per their config. Keyway reads no configuration from your servers and reports nothing to them.
