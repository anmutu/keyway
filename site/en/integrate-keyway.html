Integrate Keyway into your platform: it's one button

Published 2026-11 · For owners and frontend developers of API providers, aggregators and tool platforms

Some of your users write code in AI CLIs like Claude Code and Codex. To point those CLIs at your service, they usually copy an endpoint, open a config file, paste a key — and you lose some of them at every step. Keyway is an open-source (MIT) local gateway for AI CLIs. Put an "Add to Keyway" button in your console or docs: one click opens Keyway with your endpoint pre-filled; the user pastes an API key and they're done — never leaving your platform.

The TeapotRouter site already ships this exact entry point. This tutorial shows you how to build yours — about half an hour of work.

What your users will experience

User stateAfter the click
Keyway installedKeyway opens a confirmation dialog with endpoint and display name pre-filled; the user pastes an API key to finish. From there they can take over the CLI and switch providers anytime
Not installedThe deep link does nothing — which is why the fallback in step 3 is mandatory (send them to the Keyway download page; after installing, one more click finishes the setup)
Security boundary: the deep link carries public connection info only (endpoint, brand name). Never put a user's API key into the link — keys are pasted by the user inside Keyway.

Step 1: build the deep link

Keyway registers the keyway:// scheme on install. Link format:

keyway://connect/relay?v=1&base=https%3A%2F%2Fapi.your-domain.com&app=claude&name=YourBrand
ParamRequiredDescription
vyesFixed: 1
baseyesYour API root, URL-encoded; HTTPS with no userinfo, query string or fragment. For OpenAI-compatible endpoints supply the root — Keyway appends /v1 for Codex
appyesclaude / codex / opencode / openclaw — one button per CLI you serve
namenoPre-filled display name, up to 40 characters

Full parameter constraints and the security model live in the provider integration guide.

Step 2: place the button

The simplest form is a plain link:

<a href="keyway://connect/relay?v=1&amp;base=https%3A%2F%2Fapi.your-domain.com&amp;app=claude&amp;name=YourBrand">
  Add to Keyway
</a>

Where it converts best, in observed order:

  • The API-key page in your console — the moment a user just created a key is peak intent;
  • The "client setup" section of your docs — next to the manual Claude Code instructions, as the easy option;
  • Home or pricing pages — as a secondary touchpoint.

Brand assets and a ready-made recommendation snippet are in the guide's "Recommend us to your users" section.

Step 3: the not-installed fallback (mandatory)

Users without Keyway click the deep link and nothing happens — a bare link loses them. Use this snippet: on click, attempt to launch; if the page is still visible after ~1.5s (the app never came up), send them to the download page.

<script>
  document.querySelectorAll('a[href^="keyway://"]').forEach(function (btn) {
    btn.addEventListener('click', function (e) {
      e.preventDefault();
      var deepLink = btn.href;
      var start = Date.now();
      // if the page is still visible after 1.5s, Keyway is not installed
      setTimeout(function () {
        if (!document.hidden && Date.now() - start < 1600) {
          window.location.href = 'https://keyway.one/download.html';
        }
      }, 1500);
      window.location.href = deepLink;
    });
  });
</script>

When Keyway is installed, the OS brings it forward and your page goes to the background (document.hidden becomes true), so the redirect never fires; only genuinely uninstalled users land on the download page, which covers macOS, Windows and Linux.

Step 4: test it

  1. Quick link check: paste the keyway://… link straight into the address bar on a machine with Keyway — the confirmation dialog should appear;
  2. Full flow: paste a test key in the dialog and verify the endpoint and name in Keyway match what you expect (for Codex, check that /v1 is appended as intended);
  3. Fallback branch: click the button on a machine without Keyway (or with the scheme temporarily unregistered) and confirm you land on the download page after ~1.5s;
  4. Link hygiene: base must carry no query string or fragment and name no more than 40 characters — otherwise Keyway rejects the connection.

FAQ

Is there an approval process or a fee?

No. The deep link is an open capability of Keyway — no application, no review, no fee; it works the moment you ship it. To also appear in Keyway's preset list (users pick your name directly when adding a provider), use the listing request; the two complement each other.

Can the link carry the user's API key for a fully automatic setup?

No — and it shouldn't. Deep links carry public connection info only; keys are pasted inside Keyway (an advanced short-lived, single-use handoff grant exists — see the integration guide).

Can I see how many users arrive through this button?

The button lives on your page, so clicks are visible in your own analytics; Keyway reports nothing back to you — it's a local-first tool and never uploads to your servers.

Which CLIs are supported?

The deep link covers Claude Code, Codex, OpenCode and OpenClaw; the remaining groups like Gemini CLI are covered through preset listing.
