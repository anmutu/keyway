First launch on macOS

The app is not notarized (personal open-source project). If prompted "cannot verify developer" — right-click Keyway.app → Open; if prompted"damaged", run in Terminal:

xattr -dr com.apple.quarantine /Applications/Keyway.app

The app is fine — Gatekeeper false positive. See Blog.

In-app auto-update

Keyway has a built-in updater — new versions are offered automatically. Homebrew users can also upgrade manually:

brew upgrade --cask keyway
